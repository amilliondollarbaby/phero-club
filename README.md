# Phero Club

Brand presentation site for Phero Club, hand-poured dessert candles from the Philippines. *Scents that attract.*

- `index.html` is the built site (all images embedded).
- Edit `src/index.template.html`, put images in `assets/`, then run `python3 -I src/build.py` to rebuild.
- Real-people photos: add `assets/people-sweet-1.jpg`, `people-sweet-2.jpg`, `people-spicy-1.jpg`, `people-spicy-2.jpg` and rebuild.

Product images are concept renders.
